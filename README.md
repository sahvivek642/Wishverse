# 🎉 WishVerse – Magical Personalized Wish Generator

**WishVerse** is an interactive, frontend-only web platform designed to create personalized wish cards for birthdays, anniversaries, and special occasions.

Instead of plain text messages, WishVerse lets users generate custom shareable links and QR codes that deliver an animated gift box surprise complete with confetti!

---

## ✨ Features

* **🎁 Interactive Unboxing:** Tap the animated gift box to reveal the customized wish card.
* **🥳 Celebration Effects:** Confetti particle animation upon opening the wish.
* **📱 Shareable Links & QR Code:** Instantly copy links or share directly to WhatsApp.
* **🎨 Modern UI:** Vibrant animated gradient backgrounds and glassmorphism styling.

---

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3, Vanilla JavaScript
* **Libraries:**
  * [Canvas-Confetti](https://cdn.jsdelivr.net/npm/canvas-confetti)
  * [QRCode.js](https://cdnjs.cloudflare.com/ajax/libs/qrcodejs/1.0.0/qrcode.min.js)

---

## 🚀 How to Run Locally

1. Clone or download this repository.
2. Open `index.html` (or `Wish.html`) in any web browser.
3. Fill out the wish generator form and click **Generate Wish**!
